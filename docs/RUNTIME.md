# Windows 启动、停止与异常恢复

完成 README 的环境安装和 QQ_SETUP 的配置后，在项目根目录双击下列脚本即可。脚本会切换到项目目录，可以从桌面快捷方式或其他工作目录调用；不需要管理员权限。

| 脚本 | 功能 |
| --- | --- |
| `启动机器人.cmd` | 检查配置、数据库占用和 NapCat，启动后台守护程序和 Agent；重复点击不会重复启动 |
| `停止机器人.cmd` | 通知 Agent 正常退出，释放数据库并停止守护程序；保留 NapCat 登录 |
| `重启机器人.cmd` | 先停止，再启动；保留配置、会话和长期记忆 |
| `查看状态.cmd` | 显示守护程序、Agent、QQ 鉴权连接、NapCat 端口和最近错误 |

窗口显示结果后按任意键关闭。启动成功后可以关闭管理窗口；后台进程会继续运行。状态窗口关闭也不会停止机器人。需要停止时使用“停止机器人”，不要只关闭 NapCat 窗口。

## NapCat 与登录

启动时先检测 `.env` 中配置的连接地址。如果端口可访问，沿用现有 NapCat；端口可访问不等于登录/鉴权成功，以“QQ连接：已登录并通过鉴权”为准。

本机端口不可访问、`napcat/v4.18.42/launcher.bat` 存在且未检测到该目录的启动进程时，会打开可见的 NapCat 登录窗口。需要扫码或安全确认时由你完成，Agent 会等待并自动重连。如果已有窗口正在登录，或无法核实是否已启动，不再重复打开；请检查原窗口。其他安装目录或远程 NapCat 请自行启动。现有 `start-napcat.cmd` 仍可单独启动 NapCat。

停止和重启只管理本项目的 Agent 和守护程序，不关闭 QQ 或 NapCat，不修改白名单或令牌。手动启动的 `qq-agent --qq` 不由本管理器接管；若数据库被占用，会提示先停止原实例。

## 自动恢复规则

- Agent 进程意外退出后，依次等待 3 秒、10 秒重新启动。
- 连续运行不足 5 分钟即退出累计 3 次，暂停重试；配置错误立即暂停。修正问题后双击“启动机器人”重新尝试。
- 连续运行满 5 分钟后，下一次退出从第一档重试重新计数。
- NapCat 断线不会重启 QQ；Agent 使用现有连接重试机制恢复。
- 主动停止会写入本次运行的停止标记，守护程序不会再次拉起 Agent。下一次启动使用新的运行标记。

停止时优先取消正在进行的任务并关闭数据库。正常关闭超过限定时间才会强制终止；终止前同时核对 PID、进程创建时间和程序路径，避免 PID 被重用时误操作其他进程。不要依赖关机前正在生成的答复必定送达；原有“投递结果不确定时不重发”的规则保持一致。

这套管理器负责 Agent 进程退出恢复，不包含开机自启、守护程序自身崩溃恢复或进程卡死检测。电脑关机、退出 Windows 会话后，需要重新双击“启动机器人”。

## 状态与排障

“运行中”表示进程存在；“QQ连接”表示该轮运行最近一次已核验的协议连接状态，网络故障可能需要心跳检测后才显示断开。“最近错误”带时间，连接恢复后仍保留最近一次错误，便于排查。

- **重试已暂停**：检查配置、数据库占用和下面的日志，修正后重新启动。
- **NapCat端口不可访问**：检查 NapCat 是否运行、是否完成登录，以及连接地址。
- **端口可访问，但QQ未连接**：检查两端访问令牌、机器人账号及 OneBot WebSocket 配置。
- **守护程序未运行，但Agent仍运行**：可能是守护程序被外部关闭；用“停止机器人”清理该轮工作进程，再启动。
- **数据库被其他Agent使用**：先关闭旧的手动实例，不能同时用 CLI 和 QQ 模式打开相同数据库。

本地日志与控制文件均在 Git 忽略目录：

- `logs/agent.log`：应用事件，已有大小轮转。
- `data/run/supervisor.log`：退出码、重试和停止记录，约 1MB 轮转，保留 2 份旧文件。
- `data/run/managed-agent.stderr.log`：最近一次工作进程的控制台输出，每次启动覆盖。
- `data/run/supervisor-console.log`：最近一次守护程序的控制台输出。
- `data/run/runtime*.json`：本地进程身份、停止标记及脱敏连接状态；不包含 API Key、访问令牌或消息正文。

不要删除正在使用的控制文件或数据库。旧版 `qq-agent-process.json` 只作为历史信息保留，新脚本以 `runtime.json` 为准。

开发或批处理时，可使用不暂停的命令：

```powershell
& '.\启动机器人.cmd' --no-pause
& '.\查看状态.cmd' --no-pause
& '.\重启机器人.cmd' --no-pause
& '.\停止机器人.cmd' --no-pause
```

脚本和 `.venv` 随项目目录定位；新的仓库副本需先安装环境和配置，不包含本机 NapCat、登录信息或数据库。
