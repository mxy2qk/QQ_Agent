# /tag 插画 Skill

唯一新增发图命令为 `/tag [标签]`，群内需实际@，私聊须为授权好友。无标签时默认“风景”，例如 `/tag 初音未来`、`/tag 风景 夜景`。最多5个标签，各最多32字，按AND匹配；常见中文标签有小范围日文别名映射。偏好通过本次标签表达，不增加偏好管理、点赞或账号收藏命令。

## 当前真实访问结果

2026-11-01本机测试：Pixiv robots、公开搜索、作品详情和图片CDN robots均返回200；实际插画文件下载返回403。适配器已按受限处理，暂停5分钟，不伪造来源头、不更换代理/账号、不接入镜像或第三方随机图服务。

因此代码和图片消息通道已完成，真实Pixiv下载尚未通过验收。当前/tag可能返回“Pixiv访问受限”，不能宣称已取得或已发送图片；需要来源恢复允许访问，或另行确认合法可用的数据源后才能完成真实发图验收。

## 行为与边界

- 固定非露骨范围：只接受公开、全年龄、非AI的静态插画；检索固定safe，列表与详情双重检查xRestrict/illustType/aiType及标签，分级未知、成人/露骨或明显年龄不明确的性内容标签拒绝。不会提供R18开关。
- 按平台元数据和标签过滤，不提供R16视觉分级；Pillow只负责图片文件检查和尺寸处理，不是内容识别模型。
- 仅从第一页有限候选中随机，最多复核3个候选；多页作品只取第一张。没有符合条件的作品时不放宽过滤。
- 下载仅允许固定HTTPS域名www.pixiv.net与i.pximg.net，检查robots，禁止自动重定向；403/401/429立即停止。图片URL须匹配所选作品ID和第一页，不接受用户任意URL或本机路径。
- 单次下载最多8MiB，最多2000万像素；只接受静态JPEG/PNG/WebP。保留完整画面缩小至最长1600像素并转换JPEG，输出最多2MiB，保留可见水印。
- QQ通过受控Base64图片段发送，文本附作者与原作链接；下载缓存路径不会发给用户或模型。附件来自/tag程序结果，模型不能指定文件或发送对象。
- 每人30秒冷却，每个群/私聊会话每小时最多20次请求，失败也占用次数；同会话7天内不重复作品ID。事件去重与既有发送ACK策略沿用，结果不确定不重发。
- `/tag`由程序直接处理，不调用大模型，不写入长期记忆或模型会话轮次；未@普通文字和选择性接话均不发图。

## 本地设置

```dotenv
PIXIV_IMAGES_ENABLED=true
PIXIV_CACHE_DIR=data/pixiv-cache
```

模板默认false，启用须在本地配置后重启。独立于原有B站/贴吧开关，不读取Pixiv登录凭据。

缓存以SHA256命名，24小时过期、总量上限200MiB，取图时与后台清理周期执行清理。读取时验证ID、文件大小、过期时间和哈希，拒绝符号链接。业务Schema v5新增image_requests，保存限额、去重与作品ID，不保存图片字节；清理期限沿用原始消息保留设置。重启保留限额和作品去重，图片附件过期后提示重新/tag。

## Skill 与开发入口

`skill_specs/pixiv-random/SKILL.md`定义技能边界，`find_pixiv_image`工具只返回过滤后的公开元数据；`/tag`独立执行下载和受控图片发送。仅使用工具或`/skill pixiv-random`不代表图片已发送。

实现：pixiv_images.py为数据源/校验/缓存，service.py处理/tag与持久化限额，onebot.py渲染图片段。依赖Pillow，运行`uv sync --extra dev --locked`安装。

参考：[OneBot图片消息段](https://github.com/botuniverse/onebot-11/blob/master/message/segment.md#图片)、[Pixiv访问限制说明](https://inside.pixiv.blog/2023/05/17/102629)。这些是协议和限制依据，不表示本适配器是官方开放API。
