# 机器人操作手册

## 开始使用

- **群聊**：在白名单群中先 @机器人，再发送文字或命令，例如 `@机器人 /help`。只@机器人不带文字也会返回帮助。不@、@其他人或非白名单群不会触发。
- **私聊**：先加机器人为好友，且发送者在私聊白名单内。直接发送 `/help` 即可；临时会话不处理。
- 普通文字直接聊天，无需命令。帮助由程序直接返回，不消耗模型请求，也不会读取你的记忆内容。
- `/help memory` 查看记忆命令，`/help skills` 查看技能，`/help forget` 等查看单个命令的解释。`/memory-help` 是 `/help memory` 的兼容别名。

## 群成员与近期发言

机器人会使用当前说话者的QQ身份信息；启用授权群上下文后，还可识别群名片/昵称对应的成员，并参考该群授权成员启用后发出的普通文字。例如可@机器人问“从某成员最近的发言看，他聊过哪些话题”。不@时仍不会回复，私聊不共享给群，尚未收到的历史不会自动补齐。详情见 [群成员与上下文](GROUP_CONTEXT.md)。

群内 `/reset` 还会清除本人该群已收录的摘录，并使同群可能引用它的近期答复快照失效；保留其他成员原始摘录和明确长期记忆。

## 修改回复风格

默认使用甜软、俏皮的嘉然风格同人角色，自然简短和普通模型回复最多70字符属于固定基础。群内任何成员都可@发送 `/style` 查看、`/style set 更活泼一点，少用表情` 叠加微调、`/style reset`清除微调。set替换上一次微调，默认人格保留，不需要重复写简短或70字要求。群聊和私聊共用一份设置，立即生效并保存，支持1～1200字和换行。帮助和记忆列表等命令说明保持完整。详见 [全局回复风格](REPLY_STYLE.md)。

## 命令与作用范围

| 命令 | 用途与示例 | QQ使用范围 |
| --- | --- | --- |
| `/help` | 按当前群聊/私聊展示操作帮助 | 群@、私聊 |
| `/style [show]` | 查看当前全局回复风格 | 授权群内任何成员@、白名单好友私聊 |
| `/style set 内容`、`/style reset` | 设置或清除全局风格微调，基础规则与默认人格保留 | 授权群内任何成员@、白名单好友私聊 |
| `/help 命令名` | 如 `/help forget`，解释具体用法、限制和副作用 | 群@、私聊 |
| `/help memory`、`/memory-help` | 记忆操作总览 | 群@、私聊 |
| `/help skills` | 列出当前已加载技能及来源状态 | 群@、私聊 |
| `/remember 名称=内容` | `/remember preference=喜欢简短回答`，保存当前私聊的个人记忆 | 私聊 |
| `记住：内容` | `记住：我喜欢Python`，明确保存私有记忆 | 私聊 |
| `/remember-global 名称=内容` | 保存同平台本人跨会话记忆，仍仅本人可见 | 私聊 |
| `/remember-group 名称=内容` | `/remember-group meeting=周五读书会`，明确授权本群共享 | 群@ |
| `/memories [关键词]` | 查看记忆；`/memories Python` 搜索可访问的内容 | 私聊看本人记忆；群@仅看本群共享 |
| `/correct ID 新内容` | `/correct 12 喜欢详细回答`，纠正自己拥有的记忆 | 私聊个人记忆；群@自己创建的共享记忆 |
| `/forget ID` | `/forget 12`，删除记忆及相关来源和近期上下文 | 私聊个人记忆；群@自己创建的共享记忆 |
| `/sources ID` | `/sources 12`，查看自己的来源消息ID、操作事件和时间 | 私聊 |
| `/history 关键词` | `/history Python`，检索本人当前会话原始消息，最多20条 | 私聊 |
| `/reset` | 清除当前近期会话，保留明确长期记忆 | 私聊；群@仅清除本人该群会话 |
| `/skill 技能名 任务` | `/skill bilibili-hot 推荐3个热门视频`，指定技能 | 群@、私聊 |

所有记忆修改均需本人所有权。没有命令可读取、纠正或删除他人的私有记忆。群公开回答即使面对记忆本人，也不会使用其private/global信息。

## 序号与ID

`/memories` 可能显示：

```text
序号 1｜ID #12 [private] preference：喜欢简短回答
序号 2｜ID #8 [private] study：学习Python
```

这里删除第一条应发送 `/forget 12`，**不是 `/forget 1`**。序号每次从1连续排列；固定ID不因删除重用。先查看当前列表，再操作ID。同名记忆键会更新原记忆，自由文本按内容去重，语义纠正可用 `/correct`。

## 共享与高级命令

QQ群请用 `/remember-group` 明确创建共享信息。私聊保存的信息不会因为你在某群发言就自动共享。

`/share ID` 和 `/unshare ID` 是原群个人记忆的高级范围操作：仅针对在原群会话中、由本人拥有的personal记忆，不能把私聊记忆凭ID跨群发布。它们主要用于CLI模拟群场景；QQ中不提供私有群记忆管理，尤其`/unshare`会引导私聊。group类型记忆不能改成私有，撤销群共享信息请由创建者 `/forget ID` 删除。可发送 `/help share`、`/help unshare` 阅读说明。

## 技能与实时信息

用 `/help skills` 查看当前目录。内置 `bilibili-hot`、`tieba-hot`，也可直接说“B站热门”或“搜索贴吧Python帖子”。

- B站热门/视频详情读取的是公开候选页与标题、简介、元数据，不代表看过视频或读取完整字幕。
- B站/贴吧搜索可能因登录、验证码或风控不可用；不可用时明确说明，不编造来源或绕过访问限制。
- 时间工具已移除，未接入通用搜索或MCP。没有相应工具支持的实时信息无法核实。

## 保存和删除

默认原始消息、答复及近期会话保留7天；明确长期记忆独立保留，直到删除或指定过期。修改/删除/撤回共享会清理受影响来源原文与上下文，群共享变化可能清空该群成员近期会话。`/reset`不是删除长期记忆；删除长期记忆用`/forget ID`。应用不能清除你自行制作的外部备份。

## 常见问题

- **群内无回复**：检查是否真实@机器人、是否在群白名单内、NapCat/Agent是否运行。纯文本CQ标记不能充当@。
- **私聊无回复**：确认双方已是好友，发送者在白名单内，私聊支持已开启。
- **记忆不存在或无权操作**：确认用的是ID而非序号，且当前用户和会话拥有该记忆；其他群/私聊的记忆不能随意跨会话修改。
- **回复截断**：QQ单条回复上限2000字符；可用`/help 命令名`分项查看帮助。
- **断线期间未回复**：系统不保证补发，重连后重新发送新消息。不要反复发送删除命令或依赖旧ID。
- **退出CLI**：终端内用`/exit`或`/quit`，这是CLI控制命令，不是远程关闭QQ机器人的命令。

管理员的本地连接、令牌、白名单及启动方式见 [QQ_SETUP.md](QQ_SETUP.md)。聊天命令不能启动/关闭进程、读取令牌或修改白名单。

Windows 管理员日常可双击根目录的“启动机器人 / 停止机器人 / 重启机器人 / 查看状态”脚本，异常退出会受限重试。详见 [运行管理](RUNTIME.md)。
