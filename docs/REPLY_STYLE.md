# 全局回复风格

机器人只有一个全局风格，群聊和私聊共同使用。默认是参考B站UP主[嘉然今天吃什么](https://space.bilibili.com/672328094)气质设计的同人聊天角色：甜软、元气、俏皮，爱聊好吃的，偶尔轻轻吐槽，自称“然然”，不堆撒娇、口头禅或表情。这些是同人创作设定，不是本人发言、官方设定或账号认证；询问身份时如实说明。

日常通常1～2句、10～45字，每次模型回复硬上限70字符，标点、空白、换行和表情也计入。直接接话，省略标题、百科铺垫和总结；认真问题也先给一个简短有用的结论，等用户追问。多个笑话合计仍不超过70字符。

提示词分三层：固定基础规则 `BASE_REPLY_RULES`、默认人格 `DEFAULT_STYLE`、通过 `/style` 设置的风格微调。自然聊天、简短直接、长度和排版要求属于固定基础；/style只调整性格、语气、幽默程度等，叠加在默认人格上，不需要重复写基础要求。

## 命令

群内先实际@机器人，再输入：

```text
/style
/style show
/style set 更活泼一点，少用表情。
/style reset
```

- `/style`、`/style show`：查看当前完整风格和用法。
- `/style set 内容`：用1～1200字设置微调，支持换行，替换上一次微调；保留默认人格和固定基础规则。仅需写想调整的偏好，不必重写整个人格或70字限制。
- `/style reset`：清除微调，恢复内置默认嘉然同人风格；固定基础规则始终有效。
- `/help style`：查看命令说明。

修改由程序直接处理，不调用模型；保存成功后，下一条普通回复使用新设置，无需重启。已经在生成的答复可能仍使用请求开始时的风格。程序会把超长模型回答优先缩至句末，必要时保留前69字符并加省略号，再保存到近期会话和Checkpoint；因此/style set不能突破70字符上限。帮助、记忆列表、风格查看等程序生成的命令说明不受该上限影响。

## 谁可以修改

按使用者授权，白名单群内任何非匿名成员都能通过实际@修改风格，包括普通聊天成员名单以外的人；没有群管理员或项目所有者限制。未@的文字不能修改，其他群不能修改。好友私聊仍使用原私聊白名单，获准私聊者也能修改这同一份全局风格。

普通聊天和群摘录继续按 `QQ_ALLOWED_GROUP_USERS` 过滤。对全体群成员开放的仅是 `/style` 管理命令，不会同时放开其他命令、普通聊天或群摘录收集。QQ固定确认消息、帮助和错误信息由程序生成，保持原有含义。

## 保存与生效

风格微调保存在本地业务数据库 `reply_style_settings` 的单条记录中，重启后仍有效，不按原始消息的7天期限删除。在事件去重记录保留期内，重放旧命令使用已保存的结果，不覆盖后来的修改。恢复默认会删除微调记录。既有自定义记录兼容作为微调，不清除它们或改变原数据库结构。

风格写入和命令处理结果一起提交；没有多个人格、人格库或按成员切换的配置。修改风格保留长期记忆、群摘录和近期会话。已有会话作为上下文保留，当前请求使用最新风格；风格注入本身不写入Checkpoint。

默认文本及命令解析在 `src/qq_agent/style.py`。当前数据库Schema为v4，兼容旧v1/v2/v3升级并保留原有数据。临时模式的风格仅保留到该进程退出。

本地修改基础规则请编辑 `BASE_REPLY_RULES`，修改默认人格请编辑 `DEFAULT_STYLE`，然后重启。已有微调会继续叠加；需要纯默认人格时发送 `/style reset`。程序长度上限定义在同文件的 `MAX_REPLY_LENGTH`。

聊天命令可编辑性格、语气、幽默等风格偏好。简短自然的基础表达、70字符上限、身份真实性、来源要求、数据隔离及工具权限由固定规则或程序控制，不把整个系统提示词交给聊天命令替换。
