# 全局回复风格

机器人只有一个全局风格，群聊和私聊共同使用。默认是随和、机灵、有点嘴贫的群友：日常1～3句、通常20～80字，直接接话、适度吐槽，少用标题和长篇铺垫；讲笑话直接给指定数量的短笑话，不解释社区文化或笑点。认真求助、复杂任务或明确要求详细时可以充分解释。

## 命令

群内先实际@机器人，再输入：

```text
/style
/style show
/style set 说话更嘴贫一点，日常最多两句，认真问题再展开，不要强行玩梗。
/style reset
```

- `/style`、`/style show`：查看当前完整风格和用法。
- `/style set 内容`：用1～1200字替换当前风格，支持换行。要保留的要求也写进新内容；它不是自动润色或追加命令。
- `/style reset`：恢复内置默认群友风格。
- `/help style`：查看命令说明。

修改由程序直接处理，不调用模型；保存成功后，下一条普通回复使用新设置，无需重启。已经在生成的答复可能仍使用请求开始时的风格。模型输出长度是提示词偏好，不能保证每次严格满足字数；不会为了凑字数机械截断正常内容。

## 谁可以修改

按使用者授权，白名单群内任何非匿名成员都能通过实际@修改风格，包括普通聊天成员名单以外的人；没有群管理员或项目所有者限制。未@的文字不能修改，其他群不能修改。好友私聊仍使用原私聊白名单，获准私聊者也能修改这同一份全局风格。

普通聊天和群摘录继续按 `QQ_ALLOWED_GROUP_USERS` 过滤。对全体群成员开放的仅是 `/style` 管理命令，不会同时放开其他命令、普通聊天或群摘录收集。QQ固定确认消息、帮助和错误信息由程序生成，保持原有含义。

## 保存与生效

自定义风格保存在本地业务数据库 `reply_style_settings` 的单条记录中，重启后仍有效，不按原始消息的7天期限删除。在事件去重记录保留期内，重放旧命令使用已保存的结果，不覆盖后来的修改。恢复默认会删除自定义记录，再使用代码中的默认值。

风格写入和命令处理结果一起提交；没有多个人格、人格库或按成员切换的配置。修改风格保留长期记忆、群摘录和近期会话。已有会话作为上下文保留，当前请求使用最新风格；风格注入本身不写入Checkpoint。

默认文本及命令解析在 `src/qq_agent/style.py`。当前数据库Schema为v3，兼容旧v1/v2升级；新增设置表保留原有数据。临时模式的风格仅保留到该进程退出。

可编辑内容限定为语气、篇幅、幽默与排版偏好。基础身份、来源要求、数据隔离及工具权限继续由程序规则控制，不把整个系统提示词交给聊天命令替换。
