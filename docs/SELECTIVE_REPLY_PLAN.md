# 选择性接话实施方案

状态：设计基线，功能已实现，初始关闭。实际命令、限制和部署方式见 [SELECTIVE_REPLY.md](SELECTIVE_REPLY.md)。

## 目标与范围

复用已授权的普通群文字上下文，在少量合适的场景回应未@消息。仅限本地白名单群及指定四位成员，私聊沿用原有直接回复流程。默认人格、全局/style微调、70字符上限、7天保留和个人记忆隔离继续有效。

## 推荐默认值

| 设置 | 默认值 |
| --- | --- |
| 初始模式 | off，支持shadow观察和on真实接话 |
| 普通主动回复冷却 | 每群90秒 |
| 主动发送预算 | 每群滚动1小时最多6次 |
| 模型判定预算 | 每群滚动1小时最多20次，另设20秒判定间隔 |
| 等待观察 | 4秒，合并同一时段消息，最长等待10秒 |
| 候选最大年龄 | 入站后30秒，超时丢弃 |
| 简短续聊 | 机器人答复后30秒内，同一成员最多2次明确追问 |
| 模型判定/生成总超时 | 8秒；超时跳过 |
| 并发 | 每群最多1个待处理主动任务 |
| 输出 | 每次最多70字符、仅1条纯文本 |

续聊允许绕过90秒普通冷却，但仍消耗每小时6次发送额度及判定额度；其他成员开始新话题时取消续聊窗口。@回复不消耗主动额度，主动冷却不会拦截@。

## 触发与跳过

优先候选：明显对机器人说话并提出请求；正在和机器人交流的成员明确追问；向全群提出、机器人能提供实质帮助的问题；与当前群话题紧密相关、适合一句话接梗的轻松发言。只提到角色名字不足以触发，避免把讨论真实UP主误当作喊机器人。接梗候选同样允许模型选择跳过。

优先跳过：别人之间的明确对话、已经有人接话解决的问题、简单笑声或附和、图片/语音/表情等缺少可分析文字的消息、命令、广告刷屏及过期话题。群快速连续聊天时合并观察，避免每条消息触发一次判断。未@命令仍不执行，/style对全体群成员的既有权限例外保持独立。

## 处理流程

1. 校验可信QQ事件、授权群和成员，普通文字照常入库。
2. 规则筛选，核对开关、候选年龄、判定预算、发送预算和冷却；命中跳过规则不调用模型。
3. 延迟4秒观察，合并近期上下文；期间出现@请求时优先处理并取消旧的主动任务。新话题替换旧候选，不累积待回复列表。
4. 使用现有模型一次同时完成接话判断与短答复生成。输入仅有本群公开摘录、当前身份、授权群共享记忆及现有风格；无私聊或private/global记忆。
5. 模型输出严格校验为结构化结果：decision为reply或skip、reason_code为固定枚举、reply为文字。异常、空内容、格式错误、工具调用或超时均跳过。跳过不向群里解释，也不写入助手答复。
6. 发送前重新核验开关、额度、上下文版本、消息年龄和@优先状态。已有新消息、风格变化或来源失效时丢弃旧答复，不把旧内容硬接到新话题上。
7. 用已有受控渠道向触发群发送。正文执行70字符限制；发送结果记录去重和预算。ACK不确定时不自动重发。

候选阶段不开放工具。查实时信息或执行明确任务由用户@后进入既有Agent流程，避免普通接话演变为长时间工具任务。使用现有模型和SDK，不接入新服务。

## 队列、数据与一致性

普通观察、显式请求与主动候选分开调度。主动模型调用不占用@的串行工作队列；@和控制命令优先。共享的发送间隔通过等待实现，主动发送不应导致随后@被直接丢弃。

读取授权快照时使用持久化锁；主动模型计算放在锁外。发送前重新取得锁并校验群上下文/权限版本，防止生成期间删除记忆、reset、到期、关闭功能或修改风格后仍发出旧答复。不改变现有显式请求的记忆撤回保护。

配置、滚动发送预算及事件去重存入业务SQLite，重启不重置小时额度。候选任务和续聊窗口不恢复；断线、退出和重启时取消，不补发旧主动答复。仅发送确定成功后更新续聊状态；已尝试发送但ACK不确定同样消耗发送预算。

主动答复按原保留期保存为当前群公开会话数据，并关联触发消息，参与原有删除和失效流程。日志只记录决定类别、跳过原因、耗时、用量和额度，不记录完整判断思路或正文，不保存模型隐藏推理。

## 命令及权限建议

以下为拟新增命令，不是现有可用命令：

```text
/auto status
/auto shadow
/auto on
/auto off
/auto cooldown 90
/auto limit 6
```

群内仍需实际@执行。status显示模式、冷却剩余时间、小时额度和最近跳过原因。shadow仅判断与记录统计，不发送候选答复，同样限制模型请求次数。

推荐on/off/shadow和参数修改仅由本地配置的机器人管理者操作，status对授权成员开放；管理者通过独立QQ_CONTROL_USERS配置。现有/style允许全体群成员修改的授权不自动扩展给/auto。off优先取消尚未发送的任务，关闭后恢复仅@回复，普通消息收集开关保持独立。

## 验收与上线

必须验证：非授权群/成员不触发；普通闲聊零或低模型调用；有价值候选可回复；skip/错误/超时不发消息；@优先且不受主动额度影响；冷却和滚动额度正确；续聊最多2次；等待中被他人回答时跳过；新消息、off、删除/reset、到期或风格变化取消旧答复；重复事件与ACK不确定不重发；重启保留额度且不恢复候选；私聊内容不进入群；每次回复不超过70字符；控制命令权限正确。

先使用模拟群事件和本地WebSocket测试，再在真实群以shadow观察判断频率、跳过理由和用量。观察结果合适后由管理者/auto on启用真实接话；建议先观察20～30条有代表性的聊天，不以固定等待时间代替验收。首轮保留90秒冷却与每小时6次上限，再依据实际体验微调。
