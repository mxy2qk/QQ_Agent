# 项目决策

## 已确认

- Python 3.11+、DeepSeek兼容SDK、LangGraph、SQLite/FTS5；CLI与渠道层共用Agent Service，不引入FastAPI或多Agent。
- 原始消息、缓存答复及Checkpoint保留7天；明确长期记忆独立存活，私有默认、共享需明确授权。
- 删除/纠正/撤回共享时同步清理相关来源原文、索引和近期会话；跨库清理有持久化队列。
- global仍是同平台本人可见，不自动关联跨平台账号；群公开回复只检索group范围。
- 稳定ID不重用；显示序号从1连续排列，操作使用ID。
- QQ采用独立普通账号+NapCat/OneBot，群仅@、白名单好友私聊；使用者确认非官方风险与成员告知。
- 群白名单和好友私聊白名单独立；可用QQ_ALLOWED_GROUP_USERS进一步限制白名单群内的发言成员，不依靠昵称识别身份。实际群号与成员ID仅保存在本地配置。
- 经用户明确确认，可读取当前授权群指定成员的非@普通文字，限7天供同群问答参考，仍仅@回复，私聊不共享。默认关闭，通过QQ_GROUP_CONTEXT_ENABLED启用；不拉取旧历史，不自动转为长期记忆。
- 用户选择单一全局群友风格，使用/style查看、替换或恢复默认，不建立人格库。授权群内任何成员均可实际@修改，作为群成员普通消息过滤的命令例外；私聊仍按好友白名单。配置跨会话、跨群和私聊共享，持久保存，基础数据与工具权限保留在不可编辑的程序规则中。
- 后续按用户要求把默认风格调整为嘉然同人角色，并为模型回复设置70字符硬上限；普通问答不因要求详细而突破上限，程序生成的操作说明保留完整。截短后的答复同时用于发送、缓存、近期会话和Checkpoint，避免继续携带未发送的长答复。
- 基础表达规则、默认人格和风格微调分层：自然聊天、简短直接、70字符上限等作为固定基础，/style只在默认人格上叠加性格和语气微调；set替换上次微调，reset清除微调，既有记录兼容保留。
- 选择性接话按方案实现，初始off，shadow观察后可由管理者on启用；管理者独立QQ_CONTROL_USERS名单。默认90秒冷却、滚动小时6次发送/20次判定、20秒判定间隔、4秒观察、8秒模型期限、30秒候选有效期及最多2次续聊。@优先，判定无工具、公开数据快照，发送前复核；断线候选不恢复，ACK未知不重试。
- 用户接受非露骨插画范围，抽图只新增/tag命令，按标签表达本次偏好。固定公开safe来源，双重元数据过滤，不提供露骨/R18选项。新增受控QQ图片发送与短期缓存；真实Pixiv图片下载403时保持受限，不新增镜像/第三方服务，不宣称已完成真实发图验收。
- 只允许受控回复，不允许模型决定发送对象或执行群管理。投递不确定不自动重发。
- 公开只读来源方案已确认；B站热门/详情已验证，搜索访问限制保留，不新增收费或授权替代服务。
- 时间查询函数及QQ快捷通道按用户要求移除，暂不接入通用搜索或MCP。

## 实现取舍

小规模本地部署对持久化请求串行处理，并对数据库路径加OS锁，避免共享撤回竞态。完成回合快照作为恢复边界，正常图Checkpoint压缩保存，不自动重放中断工具。

Skill来自受信任项目Markdown，工具须程序注册和执行白名单双重校验。只注入命中技能的完整说明；未知实时信息不编造。

完整中断占位响应被识别为模型异常，最多重试一次且计入预算。失败回合和已移除工具的旧执行回合不继续进入模型上下文，原文按既定保留期保留。

## 本地文件与发布

操作帮助由应用服务层直接处理，不交给模型或记忆检索器；群/私聊按适用范围显示，兼容/memory-help，支持按命令与主题查询。操作手册在OPERATIONS.md，避免将管理员连接令牌或白名单暴露在聊天帮助中。

运行环境、NapCat、配置、数据库、账号数据和当前日志必须保留本地，不进入Git。测试缓存、旧测试数据库、安装压缩包与构建检查产物可清理。过程性修复报告已合并到当前文档；原始需求基线保存在REQUIREMENTS.md。

Windows 日常启动由本地守护程序管理，Agent 作为独立工作进程运行；3秒/10秒重试，连续短时退出3次暂停，配置错误立即暂停，运行满5分钟重置失败计数。控制命令串行、守护程序单实例、数据库锁继续生效。主动停止先协作关闭，超时后通过同一进程句柄核对创建时间和路径再终止。停止/重启不操作 NapCat；不添加开机自启或 QQ 主动消息。
